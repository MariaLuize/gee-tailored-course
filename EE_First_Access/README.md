# Primeiros Passos no Google Earth Engine / Getting Started with Google Earth Engine

---

## Português

Guia passo a passo para o primeiro acesso ao Google Earth Engine utilizando uma conta Google padrão.

### Passo 1: Acesso e Criação do Projeto
Acesse o link de cadastro: [https://earthengine.google.com/signup](https://earthengine.google.com/signup).

<img src="image%20copy%202.png" alt="Passo 1 - Tela Inicial" width="750">

Crie um novo projeto no Google Cloud inserindo apenas o nome do projeto neste momento.

<img src="image%20copy%203.png" alt="Passo 1 - Nome do Projeto" width="750">

### Passo 2: Seleção do Tipo de Organização
Na etapa de seleção do tipo de organização, escolha a opção **Outro (Other)**.

<img src="image%20copy%209.png" alt="Passo 2 - Tipo de Organização" width="750">

### Passo 3: Qualificação Não Comercial
Selecione a opção **Pesquisa individual ou uso não comercial**.

<img src="image%20copy%2010.png" alt="Passo 3 - Tipo de Uso" width="750">

No campo de justificativa, insira o seguinte texto:
> "Primeiro contato com o processamento paralelo do Earth Engine, vindo de softwares locais."

<img src="image%20copy%2011.png" alt="Passo 3 - Justificativa" width="750">

### Passo 4: Escolha do Plano
Na tela de seleção do plano, selecione a opção **Comunidade (Community)**.

<img src="image%20copy%2013.png" alt="Passo 4 - Seleção de Plano" width="750">

### Passo 5: Descrição das Atividades
* No campo de descrição do trabalho, selecione **Proteção e conservação**.

<img src="image%20copy%2016.png" alt="Passo 5 - Descrição do Trabalho" width="750">

* Na pergunta sobre atividades de uso, selecione **Pesquisa e desenvolvimento científico**.

<img src="image%20copy%2018.png" alt="Passo 5 - Atividades" width="750">

### Passo 6: Conclusão do Registro
Revise as informações e clique no botão para registrar.

<img src="image%20copy%2019.png" alt="Passo 6 - Registrar" width="750">

### Passo 7: Ativação da API
Ative a **Earth Engine API** no seu projeto do Google Cloud.

<img src="image%20copy%2021.png" alt="Passo 7 - Ativação da API" width="750">

### Passo 8: Resumo do Projeto
Verifique o resumo com as informações do projeto criado.

<img src="image%20copy%2022.png" alt="Passo 8 - Resumo do Projeto" width="750">

### Passo 9: Acesso ao Code Editor
Com o projeto criado e a API habilitada, acesse o Code Editor para iniciar o trabalho:
[https://code.earthengine.google.com/](https://code.earthengine.google.com/)

## English

Step-by-step guide to setting up first-time access to Google Earth Engine using a standard Google account.

### Step 1: Access and Project Creation
Go to the signup page: [https://earthengine.google.com/signup](https://earthengine.google.com/signup).

<img src="image%20copy%202.png" alt="Step 1 - Landing Page" width="750">

Create a new Google Cloud project by filling in only the project name for now.

<img src="image%20copy%203.png" alt="Step 1 - Project Name" width="750">

### Step 2: Organization Type Selection
Select **Other** as the organization type.

<img src="image%20copy%209.png" alt="Step 2 - Organization Type" width="750">

### Step 3: Non-commercial Qualification
Select **Individual research or non-commercial use**.

<img src="image%20copy%2010.png" alt="Step 3 - Use Type" width="750">

In the justification field, enter the following text:
> "Primeiro contato com o processamento paralelo do Earth Engine, vindo de softwares locais."

<img src="image%20copy%2011.png" alt="Step 3 - Justification" width="750">

### Step 4: Plan Selection
Select the **Community** plan tier.

<img src="image%20copy%2013.png" alt="Step 4 - Plan Selection" width="750">

### Step 5: Work Description
* Under work description, select **Protection and conservation**.

<img src="image%20copy%2016.png" alt="Step 5 - Work Description" width="750">

* When asked about intended activities, select **Scientific research and development**.

<img src="image%20copy%2018.png" alt="Step 5 - Activities" width="750">

### Step 6: Registration
Review your project details and click the button to register.

<img src="image%20copy%2019.png" alt="Step 6 - Register" width="750">

### Step 7: Enable the Earth Engine API
Enable the **Earth Engine API** for your newly created Google Cloud project.

<img src="image%20copy%2021.png" alt="Step 7 - Enable API" width="750">

### Step 8: Project Summary
Review the summary of the configured project.

<img src="image%20copy%2022.png" alt="Step 8 - Project Summary" width="750">

### Step 9: Open Code Editor
Once your project is created and the API is enabled, navigate to the Code Editor:
[https://code.earthengine.google.com/](https://code.earthengine.google.com/)
